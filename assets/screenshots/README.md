# Capturas reales de la app

Pon aquí entre 1 y 4 capturas en formato **WebP** vertical (por ejemplo 1080×2340 o 1080×1920, menos de ~150 KB cada una):

- `01.webp` — escaneo / resultados de duplicados
- `02.webp` — revisión de un grupo con vista previa
- `03.webp` — herramientas (borrosas, capturas, chats, grandes)
- `04.webp` — panel «Tu impacto» o compresión

Cuando existan, la home sustituye el mockup dibujado por estas capturas (en móvil muestra las dos primeras).
No hace falta tocar HTML: si el archivo no existe, se mantiene el mockup. Después de añadirlas, ejecuta `node build-static.js` solo si cambias textos.
